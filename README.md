# DirectSoundDemo

C# WinForms DirectSound player that loads a WAV, plays it, and exposes volume, pan, seek, device, and effect controls. It enumerates DirectSound devices, builds a SecondaryBuffer with volume/frequency/pan/effects flags, and can apply chorus, echo, flanger, gargle, reverb, or parametric EQ. Speaker layout options include stereo, headphones, and Dolby 4.0/5.1/7.1; an Upgrade backup of the same project is in the tree.
